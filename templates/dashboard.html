How a Reel is scored

Which taps count

  1. One tap per account per Reel.
  2. The account must be at least {{ r.MIN_ACCOUNT_AGE_DAYS }} days old with activity ≥ {{ r.MIN_ACTIVITY }}.
  3. Burst cap: in any {{ r.BURST_BUCKET_MIN }}-minute window, keep at most max({{ r.BURST_FLOOR }}, {{ r.BURST_MULT }} × the median window).
  4. The public number is rounded down (for example "8.2K+") so tiny manipulations don't show.
